# 架构

采用如下架构:

- main.md
  - index.md

这个仓库内包含了多个子项目, 每一个项目为一个文件夹, 内有多个文件或文件夹 对每一个文件夹, 必有一index文件以枚举其中同文件夹的所有的有效文件以及所有有效子文件夹的index文件

仓库作为文件夹存储, 因此, 仓库同样有一个索引文件, 为main.md文件

# index管理

本仓库要求, 所有子文件夹必有且只有唯一index文件作为索引, 以供用户在不打开文件夹的前提下便捷浏览所有[有效文件](./有效文件.md)以方便管理

因此,将某些文件的链接从index文件删除, 可以在不删除文件本体的情况下移出项目

# 子文件夹要求

本仓库内所有项目只允许包含没有子文件夹的资源文件夹, 除此之外不得有其他文件夹

资源文件夹不允许也没必要包含index文件以引用全部, 事实上, 如果资源比较少, 甚至根本不需要资源文件夹将资源单独存放

md文件只可处于项目文件夹, 不得存储在项目的子文件夹
