### 命名格式未定, 几个方案如下

1. 命名示例(格式说明): 20250420-谷雨.md(公元日期-节气.文件后缀)

diary并非项目 因此全部文件视作无效

2. 按照obsidian生成办法, 新的命名格式是: 

YYYY-MM-DD.md

节气写入文件内开头metadata(yaml)

3. 命名示例(格式说明): 2025-04-20-topic.md(公元日期-主题.文件后缀)

diary并非项目 因此全部文件视作无效

本文件夹内文件日期后不是接节气作为文件名 而是接主题作为文件名，当然主题可选，文件直接命名成指定格式日期(如方案2)也没问题
